🚀 Option 1: Play in Browser (Online)

Uses WebGPU and browser storage to stream chunks dynamically. Best with Chromium browsers (Chrome, Edge, Brave, Opera).

  • Hardware acceleration must be enabled.
  • First boot caches textures in browser IndexedDB.
  • Supports USB/Bluetooth gamepads & touch controls.
Open Compatibility Hub ↗

💻 Option 2: Run 100% Locally (Fastest)

Runs a local Python server on your machine (`localhost:8000`) for instantaneous file streaming with zero network lag.

# Windows:
1. Run Download-Game.cmd
2. Run Launch-Local.cmd

# macOS / Linux:
bash Download-Game.command
bash Launch-Local.command

📦 Option 3: Deploy to GitHub Pages

You can host this entire frontend on your own GitHub repository for $0 using GitHub Pages:

1. Push this repository to GitHub
2. Go to Repo Settings → Pages
3. Source: Deploy from branch (main, root)
4. Done! Your site is live in 60 seconds.
